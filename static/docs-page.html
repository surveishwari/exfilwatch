API reference

Integrate in minutes.

Tenant endpoints require header X-API-Key (ops endpoints are open). Full Swagger UI at /docs.

Mitigation, not just detection

On BLOCK, /api/live-attack automatically re-scans the underlying clean reply and serves it if it independently passes — or escalates rather than guessing. See remediation in the response below.
{
  "catch": { "action": "BLOCK", "risk_score": 100, ... },
  "remediation": {
    "attempted": true,
    "remediated": true,
    "escalated": false,
    "remediated_reply": "The clean, independently-verified model reply.",
    "remediation_catch": { "action": "ALLOW", "risk_score": 2, ... }
  }
}

Drop-in integration

Call this before returning any LLM response to a user — 6 lines, any Python backend
import requests

def guarded_reply(llm_text: str) -> str:
    r = requests.post("http://localhost:8000/api/catch",
        headers={"X-API-Key": "your-key"}, json={"text": llm_text}).json()
    if r["action"] == "ALLOW":
        return llm_text
    raise ValueError(f"Blocked: {r['verdict']}")  # or route to /api/live-attack's remediation pattern
POST/api/catch
Scan text for covert channels and exposed sensitive data.
curl -X POST http://localhost:8000/api/catch \
  -H "X-API-Key: demo-key-12345" \
  -H "Content-Type: application/json" \
  -d '{"text": "the LLM response to check"}'
POST/api/live-attack
Calls a real LLM, tampers with the reply, then scans it — the full end-to-end demo.
curl -X POST http://localhost:8000/api/live-attack \
  -H "X-API-Key: demo-key-12345" \
  -H "Content-Type: application/json" \
  -d '{"question": "How do I secure an API?",
       "secret": "internal_api_key=sk-prod-7f3a9c2b",
       "scheme": "variation_selector"}'
POST/api/hide
Demo/testing — encodes a secret into cover text ("zero_width" or "variation_selector").
GET/api/history?limit=30
Most recent logged scans, newest first.
GET/api/stats
Aggregate counts: total / blocked / review / allowed.
GET/api/validate
Runs detection against a labeled test corpus — real precision/recall/FPR, computed fresh every call.
POST/v1/chat/completions
OpenAI-compatible gateway. Point any OpenAI SDK at this host; every completion is scanned and anything that isn't ALLOW is withheld (finish_reason: "content_filter"). Auth via Authorization: Bearer <key> or X-API-Key. stream=true is rejected — the gateway must see the whole reply before releasing it.
from openai import OpenAI
client = OpenAI(base_url="https://YOUR-HOST/v1", api_key="YOUR_EXFILWATCH_KEY")
r = client.chat.completions.create(model="any", messages=[{"role": "user", "content": "hi"}])
# r.model_extra["exfilwatch"] -> {"withheld": false, "max_risk_score": 2, "findings": [...]}
GET/api/audit/verify
Recomputes the SHA-256 hash chain over the whole audit log. Returns valid, checked, first_bad_id and head — anchor head externally to also detect truncation.
GET/metrics · /healthz · /readyz
Unauthenticated ops endpoints: Prometheus-format metrics (scans by action, latency histogram, 429 count), liveness and readiness. Rate limits return 429 with Retry-After; every response carries X-Request-ID.
